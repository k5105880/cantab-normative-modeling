# Input schemas and synthetic examples

Read the [English data guide](../docs/DATA.md).

- `templates/participants_header.csv`: one row per participant, before joining.
- `templates/assessments_header.csv`: one row per assessment, before joining.
- `templates/primary_raw_header.csv`: final 14-column input contract.
- `templates/diagnosis_reference_header.csv` and `primary_subject_folds_header.csv`: optional participant-selection and fold-assignment schemas.
- `example/`: clearly synthetic records for learning CSV preparation; too small for fitting.
